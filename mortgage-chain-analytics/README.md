🏦 Mortgage Trading Analysis Dashboard (Power BI)
📊 Project Overview

This project analyzes the mortgage trading lifecycle, from loan closing to trade execution, using Power BI. The dashboard provides insights into loan readiness, trade performance, counterparty activity, and profitability.

The goal is to help financial institutions optimize trading operations, monitor performance, and improve profitability in mortgage-backed securities trading.

🎯 Objectives
* Track the loan lifecycle and trade readiness
* Analyze trading performance across counterparties
* Evaluate profitability and margins
* Identify key drivers influencing loan pricing
* Support data-driven trading decisions

📌 Key Features & Analysis

🔹 1. Loan Lifecycle Tracking
* Tracked loans from closing → audit → custodian → trade readiness
* Identified process efficiency and delays
* All loans in the dataset reached “Ready to Trade” status (100%)

🔹 2. Trade Execution Analysis
* Evaluated:
  * Trade Amount
  * Trade Premium
  * Weighted Average (WA) Price (~103.6)
* Compared pricing performance against benchmarks

🔹 3. Key Influencers (Pricing Drivers)
* Used Power BI Key Influencers visual to analyze price drivers:
  * Loan-to-Value (LTV) ratio increases → price increases
  * Debt-to-Income (DTI) ratio also impacts pricing
 
📈 Key Insights
* The portfolio shows strong operational efficiency with all loans reaching trade-ready status
* A few counterparties dominate trading volume, indicating concentration risk
* Profitability slightly exceeds target, but margins remain relatively tight
* Loan characteristics (LTV, DTI) have a direct impact on pricing strategy
* Opportunities exist to:
  * Diversify counterparties
  * Optimize pricing models
  * Improve profit margins

🛠 Tools & Technologies
* Power BI Desktop
* Data modeling & transformation
* DAX (Data Analysis Expressions)
* Interactive dashboards & financial analytics

🚀 Business Value

This dashboard helps financial analysts and traders to:

* Monitor loan pipeline efficiency
* Optimize trade execution strategies
* Improve profitability and pricing decisions
* Identify key risk and performance drivers
